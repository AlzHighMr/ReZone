# defaults/ – výchozí (doporučené) nastavení

| Soubor | Cíl u hráče |
|---|---|
| `user.ltx` | `Anomaly\appdata\user.ltx` |
| `Rookie/axr_options.ltx` | `ReZone\mods\<…Rookie Preset>\gamedata\configs\axr_options.ltx` |
| `Veteran/axr_options.ltx` | `ReZone\mods\<…Veteran Preset>\gamedata\configs\axr_options.ltx` |

Postup:
1. Nastav hru a MCM tak, jak to chceš mít jako doporučené.
2. Zkopíruj svoje soubory sem (`user.ltx` z `Anomaly\appdata\`, `axr_options.ltx` z presetu
   nebo z `ReZone\overwrite\gamedata\configs\`).
3. Nahraj na GitHub. Hráči při další kontrole aktualizací dostanou nabídku.

Složky profilů odpovídají profilům v launcheru (Rookie, Veteran). Tyto README launcher ignoruje.
