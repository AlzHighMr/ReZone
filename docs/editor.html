// Jen pro tým Re:Zone

Přihlášení

Editor mění soubory, ze kterých launcher hráčům čte novinky, volitelné mody, patche a odkazy ke stažení. Uložení = commit na GitHub, hráči změnu uvidí při další kontrole aktualizací.

Jak získat token

  1. Musíš mít na GitHubu přístup k repozitáři (správce tě přidá v Settings › Collaborators).
  2. Otevři GitHub › Fine-grained token.
  3. Repository access: Only select repositories → vyber repozitář Re:Zone.
  4. Permissions › Repository › Contents: Read and write. Nic dalšího není potřeba.
  5. Vygeneruj token a zkopíruj ho sem. Token nikomu neposílej – posílá se jen na api.github.com.
